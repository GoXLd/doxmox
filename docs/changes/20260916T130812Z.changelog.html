Summary

Overview: Proxmox VE 9.2.11 brings a minor version bump with clearer installer guidance, stronger warnings about ZFS on hardware RAID, and several storage‑related documentation updates, especially around Ceph client‑key rotation and CephFS ISO handling.

Assessment: The release is largely documentation‑focused and does not introduce new binaries, so production impact is low. However, the added ZFS on hardware RAID warning raises a high‑severity operational risk if ignored. Operators should verify storage configurations before upgrades. The Ceph changes improve clarity for key rotation procedures, reducing the chance of mis‑steps during rolling restarts.

  1. LowVersion bump to 9.2.11
    Documentation now reflects the new release number 9.2.11 and an updated timestamp (Sep 15 2026 UTC).
    Impact: All references to the previous version (9.2.10) are updated, ensuring consistency across guides.
    Action: No action required; just note the new version when planning future upgrades.
  2. LowCeph client‑key rotation list formatting
    The requirement line and the "then complete the rolling restart" step are now separate bullet points for clearer reading.
    Impact: Improves readability, reducing the chance of skipping the rolling restart step after key rotation.
    Action: Follow the two distinct steps when rotating Ceph client keys.
  3. MediumNew warning for CephFS‑ISO mounts
    If VMs have ISO images mounted from a CephFS share, they must be detached or the VMs migrated before refreshing the CephFS mount on that node.
    Impact: Prevents VM access errors or data corruption during CephFS maintenance.
    Action: Check all running VMs for CephFS‑based ISO mounts and either detach the ISO or move the VM to another node before performing a CephFS refresh.
  4. LowCephX service‑key rotation command output clarified
    The full command block was removed; the documentation now states that the command will output the options `--apply --confirm-all-clients-refreshed --restrict-ciphers`.
    Impact: Operators know exactly which flags to expect, avoiding confusion during key rotation.
    Action: Run the CephX rotation command and verify that the listed options appear in the output.
  5. LowFooter version and date updated
    All documentation footers now show the correct version (9.2.11) and release date, matching the new release.
    Impact: Ensures that readers can quickly confirm they are looking at the latest docs.
    Action: No action needed; just be aware of the updated footer when referencing docs.
  6. HighCritical ZFS on hardware RAID warning emphasized
    A table entry now clearly states: "ZFS on top of any hardware RAID is not supported and can result in data loss."
    Impact: Highlights a severe risk; using ZFS over hardware RAID can cause irreversible data loss.
    Action: Do not combine ZFS with hardware RAID. Use either pure ZFS disks or a supported software RAID configuration.
