Summary

Overview: Proxmox VE 9.2.13 brings several important enhancements: built‑in support for Software Defined Networking, tighter integration with Proxmox Backup Server, new tools for offline environments, and several Ceph‑related improvements. The release also updates the documentation version and refines command‑line help. These changes make the platform easier to secure, scale, and back up, while keeping the learning curve gentle for newcomers.

Assessment: The update is a solid incremental release. Network automation via SDN and the mature backup integration address common production pain points, raising operational efficiency. Ceph adjustments improve multi‑cluster handling and security guidance, which is critical for larger deployments. No breaking changes are introduced for existing clusters, but operators should verify the raised pve‑manager minimum version before planning Ceph migrations. Overall, the release is low‑risk and adds clear value.

Change List

  1. MediumAsynchronous storage replication and ACME certificate automation (since VE 5)
    Proxmox now supports non‑blocking storage replication and can automatically obtain and renew TLS certificates from Let’s Encrypt using the ACME protocol.
    Impact: Reduces manual steps for high‑availability storage and improves security with up‑to‑date certificates.
    Action: Enable replication on supported storage back‑ends and configure ACME in the web UI for automatic certificate handling.
  2. HighSoftware Defined Network (SDN) fully supported and default (v8.1+)
    The SDN stack, originally experimental in 6.2, is now a stable, default‑installed component that lets you design complex virtual networks through the web interface.
    Impact: Simplifies creation of VLANs, bridges, and firewall rules across the cluster, reducing reliance on manual Linux networking commands.
    Action: Review existing network configurations and migrate to SDN where appropriate; use the SDN wizard for new setups.
  3. HighDeep integration with Proxmox Backup Server
    Backup Server, written in Rust, provides incremental backups, deduplication, and fast restore capabilities directly from the VE UI.
    Impact: Significant storage savings and faster backup windows for VMs and containers.
    Action: Deploy a Proxmox Backup Server instance and configure backup jobs in the VE web UI.
  4. MediumProxmox Offline Mirror tool (released 2022)
    The Offline Mirror allows you to download subscription repositories on a machine with internet access and then sync them to isolated Proxmox hosts.
    Impact: Enables secure, up‑to‑date package management for air‑gapped or remote sites.
    Action: Create an offline mirror on a connected system and point isolated hosts to the local repository URL.
  5. LowDocumentation version bump to 9.2.13 (Sep 24 2026)
    All manuals now carry the latest revision number and date, reflecting the newest feature set and bug fixes.
    Impact: Ensures operators reference the correct documentation for the installed version.
    Action: Verify that your local docs match version 9.2.13; download updated PDFs if needed.
  6. MediumCeph ‘monhost’ handling improvement
    When a Ceph storage definition includes the `monhost` option, Proxmox treats the cluster as external and stores a separate key copy for that storage, even if monitors belong to the same Ceph cluster.
    Impact: Prevents accidental key sharing across unrelated Ceph clusters and improves security for multi‑cluster environments.
    Action: Review Ceph storage definitions; ensure `monhost` is set correctly for external clusters.
  7. LowCLI and migration updates for Ceph (pveceph description, version requirement, Cephx guidance)
    The `pveceph` helper now mentions "inspection diagnostics" in its description. Minimum required pve‑manager version for Ceph migration is raised to 9.2.19. A new "Cephx Disabled" section provides step‑by‑step guidance for disabling Ceph authentication when needed.
    Impact: Provides clearer command‑line help, enforces newer manager versions for safe migrations, and offers official guidance for special security configurations.
    Action: Use `pveceph --help` to see the updated description, upgrade pve‑manager to at least 9.2.19 before Ceph migrations, and follow the new Cephx Disabled guide if you must disable authentication.
