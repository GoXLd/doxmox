## Recommended tagline

## Alternative taglines
- Proxmox Updates. Before Everyone Else.

## UI Notes
- Use dark backgrounds
- Use orange only as accent
- Keep spacing minimal and enterprise-like
- Rounded corners: 18px
- Prefer subtle gradients over glow effects
